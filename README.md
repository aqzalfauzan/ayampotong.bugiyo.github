# Ayam Potong Bu Giyo

Website ayam potong segar di Bandar Lampung, di-host dengan GitHub Pages.

- `index.html` – halaman utama untuk pelanggan (produk, harga, layanan, cara pesan, lokasi).
- `artikel-ayam-potong-lampung.html` – artikel seputar usaha ayam potong di Lampung.

## Cara mengubah isi

Semua bisa diubah langsung di `index.html` (bisa lewat tombol ✏️ Edit di GitHub):

- **Nomor WhatsApp** – cari `GANTI NOMOR WHATSAPP` di bagian bawah file, ubah `var WA = "6281234567890";`
  (format: ganti `0` di depan dengan `62`, tanpa spasi/tanda hubung). Semua tombol "Pesan" otomatis ikut berubah.
- **Harga** – cari `GANTI HARGA`, ubah angka di setiap `<div class="price">`, lalu perbarui tanggal harga.
- **Jam buka** – cari `GANTI JAM BUKA`.
